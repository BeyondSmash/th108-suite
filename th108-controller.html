What does Connect actually do?

It hands the keyboard from the background daemon to this page and starts your layers automatically — one click, no second step. You only need it for the GIF→keys player and the LCD uploader; plain layer editing pushes to the daemon live without ever connecting.

⠿

Reactive layers only respond while this tab is focused?

This only concerns layers whose type is Reactive (whichever level they sit at — other layer types aren't affected). Once this page owns the keyboard (after Connect), it can only see keystrokes typed into this tab — a browser limit. Reactive-in-every-app comes from the background daemon: close this tab (or never Connect) and it takes over within a second.

⠿

You don't need Connect to edit layers.

With the daemon running, every layer edit pushes to it live (~½ s) and reactive keeps working everywhere. Connect is only for the GIF→keys player, onboard effects, and the LCD uploader.

⠿

Lighting froze on a firmware effect by itself?

The board occasionally stops accepting host lighting (USB events — sleep, other devices power-cycling on the bus — can trigger it). The daemon auto-fixes this after ~30 s with a USB restart (toggle in the Background-daemon card); the manual cure is unplug/replug.

⠿

Why does the "Media" layer type do nothing?

In the Layer Compositor, one of the choices in a layer's type dropdown is Media. It's reserved for playing a GIF or video inside the layer stack (so it could blend with the other layers), but that part of the engine isn't built yet — a Media layer currently renders nothing. To put a GIF on your keys today, use the GIF → Keyboard Lighting card on the Lighting tab; it plays in place of the layers.
