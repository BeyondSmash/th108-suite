FAQ — quirks worth knowing
  • Lighting went static right after Connect? Connecting hands the keyboard from the background daemon to this page, and nothing paints until you click 2 · Start layers — the static look is the keyboard's own firmware effect filling that gap.
  • Keys only react while this tab is focused? Once this page owns the keyboard (after Connect), it can only see keystrokes typed into this tab — a browser limit. Reactive-in-every-app comes from the background daemon: close this tab (or never Connect) and it takes over within a second.
  • You don't need Connect to edit layers. With the daemon running, every layer edit pushes to it live (~½ s) and reactive keeps working everywhere. Connect is only for the GIF→keys player, onboard effects, and the LCD uploader.
  • Lighting froze on a firmware effect by itself? The board occasionally stops accepting host lighting (USB events — sleep, other devices power-cycling on the bus — can trigger it). The daemon auto-fixes this after ~30 s with a USB restart (toggle in the Background-daemon panel); the manual cure is unplug/replug.
  • Media layer shows nothing? It's a placeholder for now — use the GIF → keyboard panel instead.
